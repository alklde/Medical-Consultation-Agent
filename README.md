# 医疗问诊智能体

## 项目作用

本项目是一个基于 LangGraph 与 MCP 构建的医疗问诊多智能体示例。系统能够理解用户的自然语言问题，自动判断问题类型，并交由对应的专业 Agent 处理：

- **就诊记录查询**：根据患者编号获取历史就诊记录，并按时间倒序返回最近记录。
- **初步诊断**：检索医学百科知识库，结合检索结果生成诊断建议。
- **医生信息查询**：将自然语言转换为数据库查询语句，并返回医生相关信息。
- **其他问题**：对无法处理的请求给出统一提示。

## 系统架构

系统采用 Supervisor（监督者）模式，由一个中心调度节点协调多个业务节点：

```
START -> supervisor_node
             |
             +-- guidance_node   就诊记录查询
             +-- diagnosis_node  初步诊断
             +-- doctor_node     医生信息查询
             +-- error_node      兜底处理
             |
            END
```

### 核心组件

| 组件 | 职责 |
| --- | --- |
| `supervisor_node` | 对用户问题分类，路由到对应业务节点；任务完成后结束流程 |
| `guidance_node` | 通过 MCP 工具获取患者就诊记录并整理输出 |
| `diagnosis_node` | 从 Redis 向量库检索医学知识，调用大模型生成诊断建议 |
| `doctor_node` | 由大模型生成 SQL 语句，并对输出中的敏感信息脱敏 |
| `error_node` | 处理无法识别的问题 |

### 技术栈

- **LangGraph**：编排状态图与多节点流程
- **LangChain**：大模型调用、提示词模板、Agent 构建
- **MCP（FastMCP）**：以工具服务形式提供就诊记录查询
- **Redis + 向量检索**：存储并检索医学百科知识
- **OpenAI 兼容接口**：提供大模型能力
